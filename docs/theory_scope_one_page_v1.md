## 3. 玩具默认（选项 B）

| 项 | 口径 |
|---|---|
| `inherit` | `True`（整体关系不可分摊）【已定原则】 |
| B2 推荐生成主通道 | 三形式：`use_synergy=True`、`use_density=True`、`star_m=5`、`dens_theta=0.35` |
| `p_link` | 默认 0；非零为可选增强 / 高压对照 |
| `use_balance` | 默认 `False` |
| 响应 | 重组优先（一次再分化容量）；失败则转化 |

三形式与 `p_link` 都是 B2 的表示层替身，不是母场推出的唯一形式。

## 4. 两条指标线（必须分线）

### 4.1 T2 结构记忆：只用 `R(3)` / `A_stub` / `Δτ`

验收 B/C 已通过量级：`R(3) ≳ 0.4`，多循环 `ΣΔτ` 可累积，可逆对照约为 0。  
**含义：** 种类负担相对于连接回落的滞后。  
不要用有效维回线“证明”T2。

### 4.2 有效维：只用 `locality_probe` + 声明窗

`D_eff` 规格 v0.1；主报告窗 `[0.2, 0.6]`。

**归档基线（2026-11-09）：**

- 主通道，`n=60`、12 个种子：`d_eff=1.85`（中位数 1.88）。
- 高 `p_link`，`n=60`、7 个种子（重组优先）：`d_eff=1.78`（中位数 1.80）。
- 不强行凑满高 `p_link` 的 12 个种子。
- 主通道加压 / 消散时，`d_eff` 随拆边迅速下降；不支持与 T2 同型的有效维滞后回线。

**禁写：**“已涌现物理空间维数”。
