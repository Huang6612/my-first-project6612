# 状态流宇宙模型 v2.5（把这个修改版放进仓库）

> **万相源于场，一切始于变。** 状态不是演化的舞台，状态就是演化本身。

**基本逻辑：** 万相源于场（本体，第一层），一切始于变（动力，第二层），由此长出万相（涌现，第三层）。

**宗旨：** 从最简单的宇宙底层出发，一步一步推导，看能否自然生长出现有的宇宙；不硬塞已知的物理理论。已知物理只在结构长出之后，作为对照与检验。

**标记：** 【已定】为已确认；【候选】为讨论中提出、尚待确认或检验。

## 第一层：母场本体

**定义【已定】** 母场，是在没有预设对象的情况下，宇宙作为整体所呈现的基础存在状态。

**五个性质【已定】**

1. **整体性**：宇宙作为整体存在。整体不能还原为任何一个部分，也不是各部分的简单相加；局部状态是整体状态中的分化结构，其存在受到整体状态的约束。
2. **状态性**：宇宙不是先以对象的方式存在，而是以整体状态的方式存在。状态不是某个实体所拥有的属性，并不预设独立对象存在。
3. **可分化性**：整体状态内部具有产生可区分状态差异的可能性；这些差异并非从整体之外引入，而是在整体内部形成。
4. **关系性**：状态差异之间具有内在关系，并形成相互关联、相互约束的关系结构；关系不是预设存在于对象之间，而是随着状态差异而形成。
5. **内在性**：母场不是由外部实体、外部设计者或推动者所规定；其存在及其状态关系均属于整体内部。

**起点说明【已定】** 无差异的母场是模型的**逻辑起点**，不是时间上最早的阶段。时间在第二层的演化中生长出来。

**整体存在为什么稳定（第 7 问）【已定：独立公设】** 整体是否延续，是一条独立的公设，不由内在性推出：不能因为没有外部，就推出整体必然稳定。稳定的是**存在**，不是**形态**；形态的变化正是演化。

## 第二层：母场动力学

### 0. 前提：整体延展【已定】

母场整体状态持续变化（状态流）。这是第二层的前提，也是演化不会停止的驱动：整体状态本身在延展，因此不断产生新的差异。

### 1. 区分要求与起点【已定其意；措辞候选】

状态性要求：状态必须有可区分的内容。完全无差异的整体没有内容，与"无"无法区分，作为"状态"它是不自洽的。这是第一次分化的来源，不借用任何外部东西。无差异态是一个无法维持的逻辑极限，不会"持续"一段时间再分化。

- 候选措辞：**区分要求**：任何状态要作为状态存在，其内部必须有可区分的内容。

### 2. 自洽与不自洽

- 你的定义【已定】：如果一个状态中的关系约束不能同时成立，那么这个状态就是不自洽。
- 候选修订：**自洽**，当且仅当状态中的全部约束（包括状态自身的区分要求与各部分之间的关系约束）能够**共同成立**；存在无法共同成立的约束，即不自洽。"同时"改为"共同"，因为时间尚未生成；以整个关系网络为单位，因为两两兼容不等于整体兼容。
- 用词分工：**兼容**指约束之间，**自洽**指整个状态。

### 3. 差异的定义与产生【已定】

**差异就是一分为二；之后每次，都是对已有部分再分化。** 差异不是一个实体被创造出来，而是整体状态内部出现不自洽时，原有状态无法继续维持，从而发生状态分化。最小的分化形式是"一分为二"，即整体状态内部形成两个彼此可区分的状态，而整体性仍然保持。此后的复杂差异，由已有状态的进一步分化递归产生。第一个差异没有种类，只是"区分"本身。

### 4. 差异形成的四个阶段【已定：次序；措辞为重写稿，待确认】

1. **整体延展**：母场整体状态持续变化，不同变化方式逐渐表现出来。
2. **量的差异**：差异在数量上积累：部分增多（规模），关系增多（连接），整体的约束随之增多。此时现有的性质种类仍能容纳全部约束，状态自洽。
3. **质的差异**：积累到一定程度，全部约束所需要的性质种类，超过现有的性质种类，现有的性质不再够用。差异不再只是数量上的多少，而要求出现不同的状态性质。
4. **分化**：新的状态性质出现（转化），或部分被再分化（重组），不同的状态能够被区分；整体内部呈现新的状态形成，为后续关系的形成提供条件。之后回到第 2 阶段，递归进行。

原表述（手稿）：第二阶段，"不同部分的变化程度可能大于或小于整体延展的状态特征，出现变化程度上的差异"；第三阶段，"差异不再只是程度不同，还可能表现为不同的状态性质，进而形成不同的状态"。重写后，"变化程度"改为部分数与关系数的积累，"状态性质"改为现有性质种类是否够用，这样不需要预设度量。

### 5. 临界点：用两个计数的比较表达【候选】

这个阶段没有数值尺度，也没有时间，临界不靠数值，只靠比较两个计数。

- **现有性质数 k**：此刻可用的状态性质种类数。
- **需求性质数**：在当前全部约束下（包括整体不可分摊的约束），使全部约束共同成立所需要的最少性质种类数。
- **临界点**：需求性质数超过 k 之处。不超过时自洽；超过时不自洽，发生失稳。
- **量的差异**：部分数与关系数在增长，但需求性质数不超过 k。**质的差异**：需求性质数超过 k，需要新的性质种类。
- **临界值**不是预先给定的数，而是随结构而变的：k 随转化增加，需求性质数随连接与规模增长。
- **下限**：整体的约束不可分摊（R4 的推论），所以整体关系自身所需要的性质数，是再分化无法突破的下限。该下限超过 k 时，重组不能修复，只能转化，这就是质变的必然。
- 新增约束时，需求性质数只增不减；再分化只能把可分摊的那部分降到下限，不能更低。
- 玩具中的观察（候选）：连接越强，临界规模越小（22、18、14、10）；平均性质数随规模持续增长，质变不是一次性的。详见附录 A 与整理笔记第 13 节。
- 本节取代上一版的"偏离、容限"表述：它们需要比较变化程度的大小，隐含了度量，而计数比较不需要。

### 6. 稳定性原理与相变【已定】

- **稳定性原理**：在没有外部推动者的整体系统中，状态差异通过形成关系与相互约束，使部分状态之间形成相互兼容的关系结构；当这种关系结构能够持续维持自身的基本组织形式时，即形成稳定状态。
- **相变（工作定义）**：当新的状态差异使原有关系结构中的约束条件失去相互兼容性，原稳定结构失去稳定性，状态关系发生重新组织，并形成具有不同组织形式的新稳定结构时，称为相变。

### 7. 母场动力学链【已定】

差异 → 差异产生分化 → 分化产生关系 → 关系产生约束 → 约束产生结构兼容 → 结构产生相互作用 → 整体状态 → 新的差异 → 相变 → 新的整体状态 → **递归演化**

**因果读法【已定】**：链中每一项先是前一项的果，又是后一项的因，层层递进。因果在这里读作**依赖**（后一项依赖前一项），而不是时间上的先后，因为时间尚未生成。

**关系不是树状【已定】**：整体与部分双向约束。自下而上，相互作用形成整体状态；自上而下，整体状态又作为因，约束每一个部分，并产生新的差异。因此各部分之间的关系不只沿分化的谱系传递，还经由整体状态相互牵连，关系网络不是树，而是有环的。有环，约束才可能无法共同成立，不自洽才可能发生。

### 8. 时间的生成【已定：时间在第二层生成；路径为候选】

- 客观时间 = 变化的有序性与可度量性（暂定）。
- 序：每次再分化都依赖于已有部分，"谁依赖谁"的方向就是先与后。
- 度量：稳定结构反复经历兼容、失稳、重新兼容的循环，可充当计数的标尺。

## 附录 A：内核基准与玩具模型 v2

### A.1 内核【已定为基准】

**原语：** 整体、变、区分、自洽。变是生成者，自洽是筛选者。

**规则：**

- **R1 变产生区分**：整体的变使内部出现可区分的变化方式；最小的区分是一分为二，之后每次对已有部分再分化。第一个区分没有种类。
- **R2 区分形成关系，关系形成约束**：关系与区分同时出现，关系对相关的状态施加约束。
- **R3 自洽筛选**：自洽的结构得以保持；不自洽的结构无法保持，结果是重组、转化或消散，具体由规则决定。
- **R4 整体与部分双向约束**：各部分的关系形成整体状态，整体状态又约束每一个部分。
- **R4 的推论【已定】：整体的约束不可被分化分摊。** 子部分仍是整体中的分化结构，仍受整体的同一约束；所以经由整体建立的关系，在一分为二时由两个子部分各自保留。区分关系（一分为二产生的）仍可分摊。

**附注：** 整体是否延续，是独立公设。

**质变是必然的【已定】：** 整体的约束所要求的性质数一旦超过现有性质数，再分化无法修复，只能转化。这一点由上面的 R4 推论给出。

**由内核推出的定义（不是新公设）：** 稳定 = 结构自洽并能持续维持；失稳 = 结构不再自洽；相变 = 失稳后重组为组织形式不同的新稳定结构；质的差异 = 现有性质种类容纳不下全部约束，需要新的性质种类；时间 = 依赖的序加循环提供的度量；递归演化 = R1 到 R4 反复进行。

### A.2 玩具模型 v2（`mother_field_toy_v2.py`）

**定位：** 一个随机图约束玩具，用来检验内核的逻辑能否转起来。它不是推导，不证明这些规则由母场必然推出，也不代表物理宇宙的生成机制。完整记录见 `mother_field_toy_v2_notes.md`。

**对应：** 整体 = 部分、关系、约束、性质数 k、整体配额 α；变 = 一分为二；自洽 = 是否存在满足全部约束与配额的整体赋值；R4 = 整体配额；R3 = 重组（再分化）、转化（k 加 1）、消散（关系解体）。

**验收结果**（150 个种子，每个 14 步）：

| 场景 | 结果 |
| --- | --- |
| 无配额、无跨谱系连接 | 0/150 失稳，关系始终是树 |
| 只有整体配额（α=0.6 / 0.55 / 0.5） | 8 / 28 / 133 条失稳；失稳时关系网络 100% 没有环 |
| 跨谱系关系是否带约束（q=0 / 0.5 / 1） | 0 / 134 / 148 条失稳 |
| 配额与跨谱系关系并存 | 148/150 失稳，每次响应后重新自洽 |

**观察与边界：**

1. 整体对部分的约束本身就能引发失稳，不依赖关系有环。
2. α=0.5 的陡升主要是偶数规模的取整效应（偶数 n 要求精确等分），按部分数控制后才能解释。
3. 关系有环不等于失稳：不带约束的关系不起作用，所以"关系如何形成约束"是链条上承重的一环。
4. 质的差异是否必然，取决于整体约束能否被分化分摊。可分摊时（v2 的默认设定）质变在逻辑上不是必然：不限次数的重组总能在 k=2 下修复（构造性检验，6 个实例）；一步一变、一步一筛时，一次再分化也总够用。被迫转化只在变快于筛选时出现：每 2 次以上的变才筛选一次时，34 到 39 个（共 60 个）运行被迫转化。候选的临界表达：一次筛选前累积的未修复冲突数，超过一次重组所能吸收的数目。这只限于玩具里的设定，详见整理笔记第 11 节。不可分摊时（R4 的推论，已定）：整体关系自身需要的性质数是再分化无法突破的下限，超过现有性质数时只能转化；有整体关系的场景里，80 到 100 个（共 100 个）运行被迫转化，只有配额（比例冲突）时仍是重组足够。详见第 12 节。
5. 重组使部分增多，转化使性质种类增多，消散使结构保持简单。
6. 规模与连接的量变导致质变：整体约束不可分摊时，被迫转化的运行占比随连接强度和规模单调上升（p_link=0.4 时 n=26 即 100%；0.2 时 n=40 为 100%；0.05 时 n=40 为 65%，仍在上升），临界规模随连接增强而下降（22、18、14、10），平均性质数随规模持续增长，质变不是一次性的。这是在 n 不超过 40、60 个种子范围内的趋势，不是极限证明，详见第 13 节。

**替身（均非推导）：** "≠"约束、k、α 及其取整方式、p_link 与 q_link、选择哪个部分分化、多个自洽候选之间的随机挑选、响应的触发与优先级、步数下标（不是时间）。

**玩具暴露的待决问题：** 整体对部分的约束在真实模型里是什么形式；哪些关系应带约束；重组、转化、消散由谁决定；多个自洽候选如何选择；质变已定为必然（整体约束不可分摊，已定），其成立依赖整体关系是否随连接与规模的增长而需要更多性质，在更大规模上是否继续成立尚未检验；时间如何成为物理时间。
