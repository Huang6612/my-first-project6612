## 分条：验收在测什么

### T1 ↔ A（及 X1 / 规模）

| 玩具观测 | 对应 T1 哪一环 |
|---|---|
| 仅配额、无整体关系：可有失稳，转化运行数可为 0 | 无 B2 负担时，不必进入“加细种类”。 |
| `inherit=False`：重组常够用，转化约为 0 | 局部可重分（B1）未耗尽，T1 前提不成立。 |
| `inherit=True` + 整体边 / 三形式：转化随规模或连接上升 | B2 使局部重分无法消掉阻挫，从而触发转化。 |
| 结论中写明“一次再分化”容量 | 对应 T1 的“容量 `𝓛` 内耗尽”前提；扩大 `𝓛` 可能改变是否触发。 |

### T2 ↔ B、C

| 玩具观测 | 对应 T2 哪一环 |
|---|---|
| 建压至 `k_peak≥3` 后再消散 | 加压段 `γ↑` + 减压段 `γ↓`。 |
| `R(3)`、`A_stub>0`（不可分摊） | 回落滞后的操作刻度。 |
| 可分摊 / 无整体边：难以出现高 `k_peak`，滞后弱或无 | 引理 6 类可逆对照。 |
| 多循环 `ΣΔτ>0`，可逆极限约为 0 | 厚度可累积，不只是单次脉冲。 |

### T3 ↔ D

| 玩具观测 | 对应 T3 哪一环 |
|---|---|
| 消散只拆边、不删节点 | A2。 |
| 强消散后根 `0∈V`、`V` 不减 | D1 谱系代理。 |
| 结构（`xrel`）可空仍判定延续 | D2。 |

## 使用纪律

1. 写论文或笔记时使用“与 T1（或 T2/T3）一致”，不要写“证明了母场”。
2. 回归失败时，先检查实现是否偏离公设表示（例如误把 `inherit=False` 当成默认），再讨论是否复议公设；不要用单次数值否定半形式结构。
3. 局域性探测、有效维不列入本表（属【候选探测】，尚未挂入 T1–T3）。

## 一句话

**A 旁证 T1（条件性质变），B/C 旁证 T2（滞后厚度），D 旁证 T3（谱系硬于结构核）；整表是公设推论与玩具实例的对齐清单，不是从母场到现象的推导链。**
