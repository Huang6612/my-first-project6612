## 1. 变更摘要

| 项 | 变更前 | 变更后（选项 B） |
|---|---|---|
| `p_link` 默认 | 0；随机跨谱系边常作实验主旋钮 | 0；明确为可选增强 |
| `use_synergy` / `use_density` 默认 | False | **True**（三形式主通道） |
| `star_m` / `dens_theta` | 5 / 0.35 | **保持 5 / 0.35**（阶段 2 推荐工作点） |
| `use_balance` 默认 | False | False（不变） |
| `inherit` 默认 | True | True（不变） |
| A 验收门槛 | `p=0` 全开末端转化率 ≥25% | ≥35%（本次报告为 46%） |
| 历史 `p_link=0.2` 对照 | 与默认模式混写 | 强制关闭三形式，保留 80/100 历史数字 |

**设计意图：** B2（整体层关联）的推荐生成主通道改为三形式升格；随机 `p_link` 降为可选增强，不再作为质变的唯一来源。

## 2. 代码要点

### 2.1 `World` 默认参数

- `p_link=0.0`
- `use_synergy=True`, `use_density=True`, `use_balance=False`
- `star_m=5`, `dens_theta=0.35`, `dens_min_size=6`
- `inherit=True`，重组优先，`max_resplit_depth=1`

### 2.2 自检结构调整

1. **可分摊回归（A2–A5）：** 显式设置 `use_synergy=False`、`use_density=False`、`use_balance=False`，以保持 v2 对照数字。
2. **仅 `p_link` 通道对照：** `p_link=0.2` 且关闭三形式；报告被迫转化 80/100、末态 `k≈3.32`。
3. **只有配额：** 关闭三形式且 `p_link=0`；报告 `forced=0`。
4. **A 验收（选项 B）：** 三形式主通道、`p_link=0`；与关闭三形式的对照比较，门槛为 ≥35%。
5. **B/C/D：** 高压、滞后等实验仍可使用较高 `p_link`，与主通道设置解耦。

### 2.3 复现命令

```bash
python3 mother_field_model.py
```
