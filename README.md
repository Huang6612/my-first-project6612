## 文档定位

本仓库当前重点是：

- 对齐三稿口径
- 区分“模型规则”“实验观察”“理论推断”
- 维护一个可复现、可审稿、可扩展的玩具模型说明

## 重要说明

该模型是一个有限图 + 约束系统的实验化描述，用于研究：

- 整体配额如何触发失稳
- 关系与约束的区分
- 重组、转化、消散等响应策略
- 局域性探测（`D_eff`、连接偏好、盒计数）

它不是现实宇宙或母场本体的直接证明，而是可检验的规则化工作模型。
