# 母场宇宙模型：最小可运行框架

## 一、模型定位

本模型不是在先验地设定一个“已成形对象世界”，而是在尝试从整体状态出发，研究差异、关系、结构与历史如何在约束下生成。

它的基本立场是：

- 母场不是先验的对象集合，而是一个基础存在状态；
- 差异、关系、约束和结构并非被“原样给定”，而是由状态演化生成；
- 时间并非在最初就被当作宇宙的外在参数，而是在状态序列与演化顺序中被导出。

因此，模型中的“开始”不应被理解为一个时间上的绝对起点，而应被理解为“给定一个参考状态，用于定义一条路径”。这点至关重要：时间不是模型的第一层前提，而是在第二层动力学中被推导出来的。

## 二、母场本体：不预设对象，不预设时间

我们不把宇宙理解为一堆已成形对象的堆叠，而是理解为一个总量受约束的整体状态。

在最小模型中，状态记为：

S = (a, b, c, e)

其中：

- a, b, c 是可分化的核心变量；
- e 是环境变量；
- 所有变量非负；
- 总量守恒：a + b + c + e = 10。

这意味着：

- 整体性先于对象：先有整体状态，再有局部分配；
- 差异不是预设，而是分配方式的变化；
- 关系不是先验的对象之间的连接，而是状态空间中的相互影响；
- 约束不是外加的命令，而是整体状态的内在秩序。

这里需要特别说明：

- 我们不定义“开始” = 宇宙的绝对第一瞬间；
- 我们只定义“参考状态” s0，用于描述一条路径的起点；
- 任何“初始状态”都只是模型中用于生成轨迹的一个选定状态，并不是原始时间的终极定义。

换言之，模型中的“起点”是分析工具，不是本体论中的第一性原理。

## 三、宇宙动力学：时间由状态序列导出

在本模型中，时间不是先验变量，而是状态演化顺序的结果。

设状态空间为：

X = {S | S = (a, b, c, e), a, b, c, e >= 0, a + b + c + e = 10}

定义合法邻域 N(S)：一个状态 S 可以在一步内发生以下动作：

- 重组：核心变量之间互相转移 1 个单位；
- 消散：核心变量流向环境 e；
- 转化：环境 e 流回核心变量。

这些动作构成状态变化的最小单位。

### 3.1 最小改变规则

我们定义距离函数：

d(S1, S2) = |a1 - a2| + |b1 - b2| + |c1 - c2| + |e1 - e2|

在合法邻域 N(S) 内，下一状态 S' 选择满足：

S' = argmin_{T in N(S)} d(T, T_target)

其中 T_target 是目标状态。

这就是“最小改变规则”：

- 每一步都只做最小合法变化；
- 选择离目标最近的下一状态；
- 若有多解，则再按更简单、更稳定的原则排序。

### 3.2 时间的形成

在这个框架下，时间不再是外生参数，而是状态序列：

(S0, S1, S2, ..., Sn)

其中：

- S0 是参考状态；
- Si+1 是从 Si 按最小改变规则得到的合法下一状态；
- “先后顺序”来自状态序列中的顺序，而不是一个独立的时间轴。

因此，时间在这里的意义是：

- 它是状态演化的顺序结构；
- 它不是宇宙最初就被赋予的第一性质；
- 它是从演化关系中被导出的。

这意味着我们可以说：

- 不是“宇宙从时间开始”；
- 而是“宇宙在状态空间中按序列演化，时间作为顺序关系从中生成”。

## 四、结构演化与历史延展

一旦某种状态在演化中长期稳定下来，它就变成结构。结构并不需要被当成先验对象，而是稳定状态的表现形式。它的形成方式是：

- 局部差异被关系所固定；
- 条件约束使某些状态比其他状态更容易维持；
- 反复出现的路径会在状态空间中形成历史痕迹。

### 4.1 扩展、重组、转化、消散

在最小模型中，这四种现象都能被看成同一演化机制的不同投影：

- 扩展：某个核心变量在总量约束下增加其分配比例；
- 重组：核心内部的分配关系发生重新组合；
- 转化：环境变量与核心变量相互转换；
- 消散：一部分可用秩序流入环境，减弱核心结构的集中性。

它们不是彼此独立的“魔法”，而是同一状态空间中的不同演化模式。

### 4.2 历史

在这个模型中，历史不是一个事后记述，而是状态轨迹本身：

- 早期状态是轨迹的前段；
- 后续状态是对前段结构的延续、组织与改造；
- 现有结构并非无根的“现在”，而是过去路径留下的稳定残余。

因此，“历史延展”可以被理解为：

- 结构在轨迹中反复出现；
- 过去的状态通过约束和连带效应影响未来状态；
- 现有物理过程可以被看作一条历史路径上的稳定投影。

## 五、对“开始”的修正说明

在模型中，不能把“开始”理解为宇宙的绝对时间起点。更严谨的说法是：

- 我们可以选定一个参考状态 s0 作为路径分析的起点；
- 该状态不意味着宇宙的本体论起点；
- 它只是为了构造演化轨迹而设定的分析起点。

换句更简洁的话：

“在本模型中，时间不是第一层前提，而是第二层状态演化产生的序关系；因此‘开始’并不是本体论上的原始起点，而是对一条轨迹的参考起点。”

## 六、代码对应说明

仓库中的 toy_model.py 只是这个框架的最小可运行版本。

它包含：

- 一个状态定义：State(a, b, c, e)；
- 一个总量约束：a + b + c + e = 10；
- 一组合法动作：重组、消散、转化；
- 一个最小改变规则：每一步优先选择离目标最近的合法状态。

这版代码不是宇宙真理，而是一个最小可验证机制，用来测试：

- 整体状态是否能产生差异；
- 差异是否能形成关系；
- 关系是否能形成结构；
- 结构是否能在轨迹中稳定下来；
- 这些过程是否能在最小规则下自然出现。

## 七、简短结论

该模型的核心命题可以概括为：

- 母场不是先验对象，而是整体状态；
- 时间不是先验变量，而是状态演化顺序；
- 差异、关系、结构和历史均在最小改变的动力学中生成；
- “开始”只是在路径分析中被选定的参考状态，而不是本体论上的原始起点。

这使得模型既保留了“整体性”和“状态性”，又允许进一步推导出“分化、关系生成、稳定结构和历史延展”的机制。
