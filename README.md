# 母场玩具模型 v2 整理笔记

文件：`mother_field_toy_v2.py`（v1 的 `mother_field_toy.py` 保留，用于对照）。运行：`python3 mother_field_toy_v2.py`，只依赖标准库。

## 一、v2 相对 v1 的改动
1. **R4 改为整体配额**：整体状态 = 各性质在全部部分中的占比；整体约束每个部分，任何一种性质占比不得超过 alpha；部分的取值又构成整体状态（双向）。v1 的随机加边保留为可选项 `p_link`。
2. **关系与约束分开**：`rel` 是关系图，`cons` 是带"≠"约束的关系子集。一分为二产生的关系必带约束；经由整体新增的跨谱系关系是否带约束，由 R2 规则（概率 `q_link`）决定。
3. **有终止保证的消散**；失败措辞改为"有限搜索未找到"；自洽判定写成纯函数，并有断言检查它不修改状态。

## 二、与内核的对应
| 内核 | 代码 |
|---|---|
| 整体 | `State`：部分、关系、约束、性质数 k、配额 alpha；初始 1 个部分 |
| 变（生成者） | `World.change()`：R1 一分为二；可选 `p_link` |
| 区分 | 部分；一分为二的两个子部分互相区分 |
| 自洽（筛选者） | `consistent(st)`：是否存在整体赋值，使全部约束与整体配额共同成立 |
| R2 关系形成约束 | `cons` 与 `q_link` |
| R3 | `reorganize()`：重组（再分化）、转化（k+1）、消散（关系解体） |
| R4 整体与部分双向约束 | 整体配额 `alpha` |

## 三、替身清单（都不是模型推出来的）
- "≠"约束：区分的内容被简化为"性质不同"。
- 性质种类数 k、整体配额 alpha 的数值。
- 选择哪个部分分化、如何分配邻居、在多个自洽候选中随机挑一个（对应待决的"选择原则"）。
- 步数下标只是依赖顺序的账本，不是生成的时间。
- 搜索是有限的：没找到不等于无解。

## 四、验收结果（150 个种子，14 步）
| 场景 | 结果 |
|---|---|
| A1 起点 | 1 个无差异部分，一次变之后 2 个部分，自洽 |
| A2 无配额、无跨谱系连接 | 0/150 失稳，关系始终是树 |
| A3 只有整体配额 | alpha=0.6：8/150；0.55：28/150；0.5：133/150；**失稳时关系网络 100% 没有环** |
| A4 R2 的作用（无配额，p_link=0.4） | q_link=0：0/150；0.5：134/150；1.0：148/150 |
| A5 两者并存 | 失稳 148/150，每次响应后重新自洽 |

## 五、发现
1. **整体对部分的约束本身即可引发失稳，不依赖环。** 这修正了 v1 里"没有环就不会失稳"的说法，那是"≠"约束这种类型的数学性质，不是内核的必然。
2. **关系有环并不等于失稳。** q_link=0 时关系图有环（关系数 18.9 > 部分数 15），但带约束的关系仍是森林，一次失稳都没有。R2（关系如何形成约束）是链条上承重的一环。
3. **重组总是够用。** 每次失稳只需一次再分化就能修复，k 始终是 2，质的差异（新性质）从未被迫出现。三种结果走向三种世界：重组使部分增多（复杂化），转化使性质变多（k≈2.9），消散使结构保持简单。
4. alpha 越严，失稳越频繁，且是阶跃式的（0.6 到 0.5 之间急剧上升）；alpha 是替身，没有推导。

## 六、下次整理要决定的事
1. 整体配额只是"份额上限"的一种写法；真实模型里整体对部分的约束是什么形式？
2. R2 的规则：什么样的关系应当带约束？目前只有"区分必带"与"经由整体的关系看概率"。
3. 重组、转化、消散由谁决定、何时选哪个（"规则随演化"）。
4. 在多个自洽候选之间的选择原则（随机只是替身）。
5. 质的差异在内核里是必然还是特例（发现 3）。
6. 未检验：时间的度量、整体延续、稳定性在扰动下的维持、维度/常数/熵增。

## 七、审稿口径修正版：需要明确写清的部分

以下内容是根据审稿意见整理出的必须补充说明，目的在于避免把玩具模型当成现实宇宙解释。

### 7.1 把“整体配额”写成可直接判定的数学条件

对 n 个部分、k 种性质，若每种性质的占比不超过 α，可明确写为：

∀ c ∈ {1, ..., k}, N_c / n ≤ α

其中 N_c 是取值为 c 的部分数量。由于数量为整数，每种性质最多可有 ⌊α n⌋ 个部分；因此，至少要满足：

k ⌊α n⌋ ≥ n

才有可能满足配额。这只是必要条件，约束图仍可能让整体无解。

这也提示 A3 的阶跃现象可能部分来自整数门槛，而不一定反映更深的“整体涌现”。特别是 k = 2, α = 0.5 时，两个性质必须恰好各占一半；若 n 为奇数，配额本身就不可能满足。建议按节点数、奇偶性和该可行性条件分组报告结果。

### 7.2 说明“部分”“差异”和“性质取值”不是同一个概念

当前笔记容易让读者把“生成两个不同的部分”与“两个部分必须取不同性质”混为一谈。建议明确区分：

- 部分差异：两个部分在模型中的身份或生成谱系不同；
- 性质差异：两个部分被赋予不同的性质值；
- 约束差异：模型要求它们不能取同一性质值。

一分为二必然产生两个部分，但“子部分之间必须满足 ≠”是当前模型的规则替身，不是从部分差异自动推出的结论。

### 7.3 区分关系图与约束图，并限定 A2、A4 的说法

建议明确写成：

G_rel = (V, E_rel)
G_cons = (V, E_cons)

且 E_cons ⊆ E_rel。

再说明“树”“森林”“有环”分别是指哪一张图。A4 的结果更准确的表述是：

- 关系图出现环并不足以导致失稳；
- 在这组参数下，约束边保持森林，因此没有观察到失稳。

这不证明所有有环的关系图都稳定，也不证明森林约束在配额存在时必然稳定。

若关系图允许重边，也要说明“关系数大于节点数”是否足以支持“有环”的判断；对多重图与简单图，解释可能不同。

### 7.4 补全自洽判定的结果类型

“有限搜索未找到”需要与“证明无解”分开。若程序穷举了全部 k^n 种赋值，可报告 SAT 或 UNSAT；若只搜索了部分候选，应报告 SAT、UNKNOWN 或“有限搜索未找到”，不能把未找到解当成无解。

另外，“纯函数”和“断言不修改状态”是两个不同的保证。建议在文档中说明如何检查无副作用（例如比较调用前后的状态副本），并保证一致性判断不会因随机数、缓存或状态字段变化而改变。

### 7.5 把 R3 的触发条件、作用范围和失败结果写出来

目前“重组总是够用”应限定为：

- 在本次参数和已测试轨迹中，一次再分化足以恢复自洽。

这不是对所有状态的保证。建议对每个算子给出：

- 何时可选；
- 如何选择目标节点或边；
- 一次操作具体改变哪些状态量；
- 操作后是否必须重新检查自洽；
- 若重组、转化、消散都未恢复自洽，模型如何处理。

尤其是消散：若删除关系或节点会改变配额中的部分总数，消散不一定单调地改善自洽。所谓“有终止保证”，应说明保证的是：

- 循环必定停止，还是
- 停止时一定得到自洽状态。

两者不能混用。还应说明硬编码删除上限触发时返回什么结果。

### 7.6 补全实验的可复现信息，并收窄结论措辞

A1–A5 建议附上完整参数：初始条件、步数、k、α、p_link、q_link、随机种子范围、算子选择规则，以及“失稳”“响应后自洽”的计数口径。还要说明每种统计的分母；例如“148/150”是 150 个种子中至少发生一次失稳，还是总失稳次数占比。

“三种结果走向三种世界”适合改成更严格的观察性表述，例如：

- 在当前实现与参数下，三种响应策略分别呈现出部分数量增加、性质种类增加、结构规模受限等不同倾向。

这样不会把由预设规则产生的结果误写成内核推导。

### 7.7 建议新增一节：执行流程和模型边界

在“与内核的对应”后加入一张执行流程：

生成候选状态 → 检查一致性 → 若不一致则选响应算子 → 更新状态 → 再检查

说明何时抽样、何时判定成功、何时停止。

并在“发现”后增加一个模型边界：

- 目前模拟验证的是这组规则下的图约束行为；
- 它不是从“母场”本体推导出这些规则；
- 它也不是现实宇宙生成机制的证明。

### 7.8 说明“步数下标不是时间”

把“步数下标只是依赖顺序账本”保留，并进一步说明：

- 它还不是物理时间度量；
- 要建立物理时间，至少需要额外定义状态间隔如何映射为时长，以及这种映射如何和可观测量联系起来。

## 八、版本判断

整体上，v2 的整理方向是清楚的。最值得优先检查的是 α 与节点数带来的离散可行性门槛，因为它可能直接解释 A3 的阶跃式失稳；其次是把“响应终止”与“成功恢复自洽”分开定义。

在审稿口径上，v2 的关键修正是：

- 不再把关系和约束混为一谈；
- 不再把有限搜索失败直接等同于无解；
- 不再把 toy model 当成现实宇宙解释；
- 更明确地把实验观察与理论推导分开。

这使它更接近“可说明、可修正、可继续展开”的研究笔记，而不是哲学化叙事。
