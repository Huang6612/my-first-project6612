## 项目概述

本仓库记录了一个面向“整体性/局域性/结构重组”问题的有限图约束玩具模型。该模型并不声称直接解释现实宇宙，也不声称从“母场本体”推出严格定理；它更接近一个可运行的研究原型，用于测试以下问题：

- 关系如何形成约束；
- 区分（`≠`）与整体配额如何共同诱发失稳；
- 重组、转化、消散三类响应如何影响稳定性；
- 局域性可否通过有效距离 `D_eff`、连接偏好、盒计数等指标被观察到。

核心思想是：通过有限状态、有限分裂、有限响应和可复现随机种子，研究在约束系统中，结构性差异与整体性压力如何一起引发“局部重组”和“整体转化”。

## 模型定位

本模型属于“toy model + constraint satisfaction”范式，具备以下特点：

1. 采用有限图表示对象、关系和约束；
2. 以分裂（split）作为生成机制；
3. 以一致性判定（consistent / SAT-UNSAT）作为筛选机制；
4. 以重组、转化、消散作为响应算子；
5. 以局域性探测指标（谱系距离、图上阻抗、有效距离、盒计数）作为观察面。

## 核心术语

### 1. 整体状态

整体状态由：

- 部分集合 `V`
- 关系图 `rel`
- 约束图 `cons`
- 整体关系 `xrel`
- 颜色数 / 性质数 `k`
- 配额参数 `alpha`

构成。

### 2. 分裂（变）

分裂操作表示一个部分被“拆分”为两个子部分，并产生区分边（`≠`）。在本模型中，这一步是生成机制的基本事件。

### 3. 自洽（consistent）

若存在一种整体赋值使全部约束同时成立，则认为状态自洽；否则为失稳状态。该判定来自图着色/约束满足问题的投影。

### 4. 三类响应

- 重组：尝试在有限容量内进行再分化；
- 转化：增加颜色数 `k`，扩大可用性质空间；
- 消散：删除关系，减少约束压力。

## 三稿对齐与说明

本仓库中对三稿关系做了明确区分：

- 整理笔记：模型本体与演化机制；
- 局域性探测规格：`D_eff`、连接偏好、盒计数；
- 选项 B 纪要：主通道从 `p_link` 调整为三形式（协同、密度、配额）；
- 本稿（对齐稿）：统一术语、解决历史冲突、明确已定/候选/替身/否决的边界。

关键修正包括：

- 区分“关系图”和“约束图”是不同层次；
- 区分“整体关系”与“不可分摊”不是同一命题；
- 把“有限搜索未找到”与“证明无解”明确分离；
- 把实验结论与理论解释明确分开。

## 研究问题

本仓库所关心的问题主要包括：

1. 整体约束是否能够单独诱发失稳？
2. 关系与约束是否必须区分？
3. 重组是否能在默认容量下不断修复失稳？
4. 何时必须转化（`k` 增加）？
5. 局域性是否存在可观测的稳定指标？
6. 这些现象是否能用更明确的几何/图谱指标进行稳健观察？

## 关键结论（当前说明）

当前说明稿中的重要结论包括：

- 区分关系必须带 `≠` 约束；
- 整体关系在默认 `inherit=True` 下不可分摊；
- 配额参数 `alpha` 具有明显的离散门槛效应；
- 在指定条件下，若默认重组容量内无法恢复自洽，则转化是唯一继续路径；
- 局域性探测通过有效距离和盒计数可以作为旁证指标，而不是直接证明本体命题。
